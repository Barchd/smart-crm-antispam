Документация для интегратора

Передайте этот раздел PHP-разработчику или интегратору 1C.

Endpoint

POST {{ request.scheme }}://{{ request.get_host }}/api/v1/intake/lead

Обязательные заголовки

ЗаголовокЗначение
Content-Typeapplication/json
X-TimestampUnix timestamp (целое, окно ±5 мин)
X-SignatureHMAC-SHA256 hex(secret, body)

Опциональный заголовок (internal trust)

ЗаголовокЗначениеЭффект
X-Intake-Trust internal Отключает IP/UA velocity-проверки. Только для backend-систем с одного IP-сервера.

Пример PHP (подпись)

$secret = getenv('WEBHOOK_SECRET');
$body   = json_encode($payload, JSON_UNESCAPED_UNICODE);
$ts     = time();
$sig    = hash_hmac('sha256', $body, $secret);

curl_setopt_array($ch, [
  CURLOPT_URL        => 'https://example.com/api/v1/intake/lead',
  CURLOPT_POST       => true,
  CURLOPT_POSTFIELDS => $body,
  CURLOPT_HTTPHEADER => [
    'Content-Type: application/json',
    "X-Timestamp: $ts",
    "X-Signature: $sig",
  ],
]);
Ротация: после смены секрета в старом .env или PHP-коде ответы перестанут быть подписаны корректно. Обновите переменную окружения на PHP-сервере до нажатия «Сгенерировать».

Сгенерировать новый секрет?

Старый секрет перестанет работать сразу. Все подписанные запросы с PHP-сайта и других интеграторов будут возвращать 401 до обновления их переменной WEBHOOK_SECRET.

Обновите интегратор после копирования нового секрета.
