# D-009: Customer Messaging отделён от Admin Ops

**Дата:** 2026-07-29  
**Статус:** принято

## Контекст

Telegram может быть и каналом общения с клиентом, и инструментом администратора. Смешение этих контуров создаёт архитектурный риск.

## Решение

Два независимых контура:

| Контур | Назначение | UI |
|--------|-----------|-----|
| Admin Ops | Модерация заявок, retry, статистика | `/requests/` (head) |
| Customer Messaging | Переписка менеджера с клиентом | `/deals/{id}/` (чат-блок) |

Channel adapters (`channels/`) — plugin-слой. Замена Telegram на WhatsApp требует только нового adapter, не переписывания домена.

## Последствие

- `channels.Dialog` привязан к клиенту и сделке, не к заявке
- Menager видит только свои диалоги
- Outbound message всегда требует подтверждения менеджером (нет автоотправки)
