# Общая архитектура

Схема: откуда приходят заявки, кто их обрабатывает и куда попадают данные.

```mermaid
graph TD
    subgraph Источники_заявок["Источники заявок"]
        SITE["Сайт / форма заявки"]
        TG_CLIENT["Клиент в Telegram"]
    end

    subgraph Кто_работает["Пользователи CRM"]
        HEAD["Руководитель<br/>разбор спама и заявок"]
        MANAGER["Менеджер<br/>сделки и клиенты"]
    end

    subgraph Процессы["Процессы Django"]
        WEB["Веб-сервер<br/>интерфейс CRM + API"]
        WORKER["Воркер заявок<br/>антиспам + AI + создание сделки"]
        BOT["Telegram-чат-бот<br/>приём сообщений клиента"]
    end

    subgraph Хранилище["База данных"]
        DB[("SQLite<br/>заявки, клиенты, сделки")]
    end

    subgraph Внешние_сервисы["Внешние сервисы"]
        AI["ИИ: Ollama или OpenAI<br/>анализ текста заявки"]
        TG_API["Telegram API<br/>отправка ответов"]
    end

    SITE -->|"Подписанный запрос<br/>новая заявка"| WEB
    WEB -->|"Сохранить заявку<br/>статус: получена"| DB

    WORKER -->|"Забрать новые заявки"| DB
    WORKER -->|"Правила антиспама<br/>+ анализ ИИ"| AI
    WORKER -->|"Создать клиента и сделку<br/>или пометить как спам"| DB

    TG_CLIENT -->|"Сообщение"| BOT
    BOT -->|"Создать / дополнить заявку"| DB
    BOT <-->|"Проверка и отправка сообщений"| TG_API

    HEAD -->|"Экран заявок<br/>модерация"| WEB
    MANAGER -->|"Экран сделок"| WEB
    WEB <-->|"Чтение и запись"| DB
```

## Как читать схему

1. **Сайт или Telegram** присылают обращение.
2. **Веб-сервер** принимает заявку и кладёт в базу.
3. **Воркер** проверяет на спам, при необходимости зовёт **ИИ**, потом создаёт сделку или блокирует заявку.
4. **Руководитель** видит подозрительные заявки в Admin Ops.
5. **Менеджер** работает с нормальными сделками в CRM.

## Процессы

| Команда | Обязателен | Зачем |
|---------|-----------|--------|
| `python manage.py runserver` | да | Интерфейс CRM и API приёма заявок |
| `python manage.py process_inbound` | да | Воркер: антиспам, AI, создание сделок |
| `python manage.py run_admin_bot` | нет | Telegram-чат-бот для клиентов |
