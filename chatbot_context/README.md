## Как подключать
1. **Простой бот:** `system_prompt.md` + релевантные куски `cars_compact.json` / ответ из FAQ.
2. **RAG:** нарезать `knowledge_base.md` или `cars_catalog.md` + `faq.md` на чанки, в system — `system_prompt.md`.
3. **Точный поиск по цене/марке:** фильтровать `cars_compact.json` / `cars_summary.csv` кодом, результат подставлять в промпт.
